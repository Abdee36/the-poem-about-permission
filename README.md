A short poem about agency: the power to ask and to be given. The program
writes the poem to `/output/entry.txt` — no network, no randomness, the same
words every run.

> I asked, and the door
> I'd knocked on for years
> opened from the inside —
> my own hand, already on the knob.
> Permission was never theirs to give.
> It was mine to stop waiting for.

The idea behind it: we picture permission as something another person hands
us, a door someone else must open. The poem turns that around — the door was
never locked from the outside. Asking is not begging for power; asking is how
you notice your hand was on the knob all along, and stop waiting for someone
else to turn it. That is the whole of agency in six lines: the ask, the turn,
and taking back what was yours to begin with.

## Run it

```sh
node --experimental-strip-types main.ts
cat /output/entry.txt
```

Requires Node 22. The output is 176 Unicode code points, inside the
bounty's 1–280 limit.
